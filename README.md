# Лабораторные работы по ОСРВ FreeRTOS (STM32)

**Платы:** Nucleo-64 / STM32F103RB  
**Среда:** Arduino IDE + STM32FreeRTOS  

## Содержание:
* **LAB0:** Настройка среды и простейшая задача мигания светодиодом (LED1).
* **LAB1 (Вариант 7):** Управление задачами через UART (команды B, D, X, Y) с использованием приоритетов и задержек FreeRTOS.
